# TOGAF 10 Study Resources

This repository contains the study materials that were most useful for me to prepare for the **TOGAF 10 Foundation (Level 1)** certification. The exam code is `OGEA-101`.

## Repository Contents

- **The TOGAF Standard, 10th Edition - Introduction and Core Concepts** (PDF)

  - Official publication by The Open Group covering foundational concepts of TOGAF 10

- **The TOGAF Enterprise Architecture Foundation Study Guide** by Van Haren Publishing (PDF)
  - Comprehensive study guide for TOGAF Enterprise Architecture Part 1 exam preparation
  - Similar to **The TOGAF Standard, 10th Edition - Introduction and Core Concepts**, but more exam-focused

## Recommended Reading Order:

1. Start with the official **TOGAF Standard, 10th Edition** for foundational knowledge.
2. Complete your preparation with the **Foundation Study Guide** for exam-specific training.
